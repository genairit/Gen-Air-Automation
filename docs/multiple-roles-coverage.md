## Targeted execution

Use the repository's normal Playwright configuration, an unused set of four ports, explicit app
checkout paths, and a fresh `GEN_AIR_ARTIFACTS_DIR`. Authentication is established through the real
API. Google Places is faked locally; Google Drive is unconfigured except for the existing Drive
regressions' browser mocks. No shared Supabase or production document integration is exercised.

Feature specs: `tests/auth/multiple-roles-*.spec.ts`.
Affected regression specs: `auth/role-contract`, `auth/role-access`, `auth/role-migration`,
`auth/feature-permissions-ui`, `employees/employees`, and `tasks/tasks`.
Run those specs only, not the full suite at feature stage.

Backend focused checks include auth/user services, role migration/concurrency, project-member
eligibility, project task initialization, and task components. Run migration/concurrency checks
from an OS temporary working directory with temporary links to the checkout's migrations and
dependencies: their test database paths derive from `process.cwd()`.
Frontend focused contracts are `tests/user-role.test.mjs`, `tests/session-permissions.test.mjs`,
and `tests/apartment.test.mjs`; these run without generating source files.

Actual revision fingerprints, counts, commands and private artifact paths belong in the QA
handoff, not in this maintained coverage document. Independent Automation review and coordinated
frontend workflow pins precede final exact-revision QA.
